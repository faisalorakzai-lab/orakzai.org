# Native Home UI — foundation reference

## Scope and source

The user supplied `ORAKZAI-ui-foundation` as a visual reference and explicitly
rejected banner artwork with baked-in writing. Its Expo implementation, demo
records, fake member counts, events and unavailable `/manus-storage` images
were not imported.

The actual Flutter Home route remains:

`lib/main.dart` → `OrakzaiApp` → Home tab → `HomeScreen`.

The five bottom tabs and their routing remain unchanged. No Services feature,
backend change, authentication change or permission change is part of this UI
iteration.

## Current presentation

- Navy, warm gold, cool off-white surfaces and compact native cards.
- Short logo/greeting header and working global-search entry.
- Five clean, locally bundled photographic backgrounds.
- Separate native Flutter heading, subtitle and CTA widgets over a navy
  contrast gradient. No old text-heavy poster appears in the active carousel.
- Four request/community action tiles, responsive from stacked rows to a
  two-column or four-column grid.
- Real announcements, approved program descriptions, authorized statistics,
  community updates, and an honest unconnected-openings state.
- Bundled Manrope weights and existing Arabic-script fallback retained.

Photographs are representative stock imagery, not claims about organization
projects, personnel, locations, services or outcomes. Sources and licenses are
recorded in `assets/images/home_photos/SOURCES.md`.

## Preserved behavior

The reusable carousel retains four-second auto advance, horizontal swipe,
accessible indicators, pause/resume, touch/focus pauses, lifecycle/off-tab/
covered-route pauses, reduced-motion support and controller/timer disposal.

Banner geometry measures the native text at the current scale and includes
Material's 48px minimum button target. The photo can be cropped with
`BoxFit.cover`; the native text is never part of that bitmap.

The primary request action remains visible on the normal 412×915 phone layout.
Larger accessibility text can grow the page vertically without clipping.

Search, private request submission, emergency disclaimer, authentication
gates, program-area scroll, data refresh and independent error/loading states
continue using existing controllers and services.
